Gavvas Astro Analyzer – iPhone PWA

Wichtig:
Diese App ist für den Betrieb über HTTPS gedacht. Eine direkte Vorschau der index.html
in der iPhone-Dateien-App führt JavaScript und Netzwerkzugriffe nicht zuverlässig aus.

Installation:
1. Den gesamten Ordner auf einen HTTPS-Webspace laden.
2. index.html in Safari öffnen.
3. Teilen -> Zum Home-Bildschirm.
4. Danach startet Gavvas Astro Analyzer wie eine App.

Live-Daten:
Ortssuche und Wetter werden über Open-Meteo abgerufen. Dafür ist eine Internetverbindung nötig.
